Book grammar · discovery with slight surprise

～と…た・～たら…た　A

Discovery: “When I did A, I found that B was already true.”

MeaningFormsExamplesComparisonsJLPT tips

Meaning in plain English

The first action reveals a fact that was already there. Opening a present reveals its contents; looking outside reveals the snow. The action lets you notice the situation—it does not create it.

The second clause often contains ていた, あった, いた, or だった. These describe what you found at that moment. Slight surprise is common, but the sentence need not express a dramatic shock.

This is a report of a real past experience. Although と follows a nonpast verb, the ending tells you the whole scene is in the past. Translate it as “when,” not automatically as “if.”

Think of it this wayFreeze the scene just before the first action. If B was already true and A only revealed it, read this as discovery.

How to build the pattern

Dictionary form + と
開ける → 開けると; 見る → 見ると; 行く → 行くと. In this past narrative, keep the first verb nonpast and put the discovered situation in the second clause.
た-form + ら
開けた → 開けたら; 見た → 見たら; 行った → 行ったら. Use the real た-form: 読む → 読んだら, する → したら, 来る → 来たら（きたら）.
An ongoing or resulting state: ていた
寝ていた = was sleeping. 来ていた = had arrived and was there. The verb decides whether ていた describes an ongoing action or a state resulting from an earlier event.
Other state endings
人がいた = someone was there; 手紙があった = a letter was there; 空だった = it was empty. A discovery does not require ていた in every sentence.
Two roles in the scene
In the book’s discovery pattern, one person notices a different person, thing, or situation. 私が開ける → 人形が入っていた. The observer is often omitted in Japanese.

Read the Japanese and translation, then identify what is happening before and after the connector.

Book wording and English gloss
Book overview

「たら・ば・と・なら」には、「もし…」というのにもいろいろながあります。

たら, ば, と, and なら have uses beyond hypothetical “if” conditions. This group focuses on past discoveries and events, quick sequences, and paired facts.

Book formation

　 ＋と
　たら

Discovery: verb dictionary form + と, or verb た-form + ら.

Book explanation

「～のをすることで、…というに。」…はからいるをで、がある。「…ていた」のがよく。～と…のは。

Doing A leads the speaker to notice B, a state already in existence, often with slight surprise. B commonly uses ていた. The observer in A and the subject of the discovered situation in B differ.

Book example

A①プレゼントをと、がいた。

When I opened the present, I found a doll inside.

Clue The doll was inside before the present was opened.

How to read this example

入っていた describes the resulting state “was in there”; it does not say the doll entered afterward.

Book example

②をと、そこにがいた。

When I stepped outside the entrance, several large men were standing there.

Clue The men were already outside when the speaker stepped out.

How to read this example

いた establishes their presence, while 出ると introduces the moment of discovery.

Book example

③のを、なだった。

When I looked out the window, the scene was completely white with snow.

Clue Looking reveals the existing snowy view.

How to read this example

だった is a past noun-predicate ending; a discovery can use it instead of ていた.

Expanded explanation

The first action opens a scene in which the speaker discovers an already-existing fact. The second clause therefore often uses ていた or another state expression.

Added examples

Apply the same distinction in these additional situations.

Added example

ドアをと、がいた。

When I opened the door, a cat was sleeping there.

Clue The cat was already sleeping.

How to read this example

寝ていた is ongoing activity discovered when the door opens, not an action caused by opening it.

Added example

に、はもういた。

When I arrived at the station, the train had already left.

Clue The departure happened before the arrival at the station.

How to read this example

もう + 出ていた conveys “had already left,” which is a state discovered too late.

Added example

をと、はだった。

When I opened the box, it was empty.

Clue The box is found empty.

How to read this example

空 here means “empty” and is read kara, rather than sora (“sky”). 空だった names the box’s existing condition; opening does not empty it.

Added example

へ、がぬれていた。

When I went outside, the road was wet.

Clue The wet road is discovered outside.

How to read this example

ぬれていた describes its wet state; the speaker’s going outside does not wet it.

Do not confuse it with…

Discovery ↔ a new result
箱を開けると、人形が入っていた: the doll was already inside. 箱を開けると、おもちゃが飛び出した: opening triggered a new event. Compare triggered results.
Discovery ↔ an event during an activity
見たら focuses on taking a look and finding something. 見ていたら sets up an ongoing activity during which an event occurs. Compare chance events.
と ↔ なら
A discovery tells what actually happened. なら takes a premise and responds to it; it does not by itself narrate arriving and finding something. Review Lesson 6: なら.
と／たら ↔ たところ
～たところ can report what you found or what resulted after trying an action, often in a more report-like style. Do not confuse it with Vたところだ, “have just done,” from Lesson 1: ところ.

JLPT approach

  1. Read the second clause first: was someone already there, was something already happening, or had something already finished?
  2. Treat もう as a timing clue. It supports an already-established situation, but still check the verb and meaning.
  3. Do not replace every past verb with ていた. Choose the state you discover, not simply the longest or most complicated answer.

Use clues to interpret the whole sentence. A single word is not a guaranteed answer shortcut.

Useful expression

確認してみたら、日付が違っていました。

かくにんしてみたら、ひづけがちがっていました。

When I checked, I found that the date was wrong.

確認してみたら frames checking as the action that reveals the mismatch. It does not mean checking changed the date.

Book grammar · chance event

～と…た・～たら…た　B

Chance event: “While A was going on, B happened.”

MeaningFormsExamplesComparisonsJLPT tips

Meaning in plain English

An activity is already in progress when an unexpected event happens. You are watching television when the phone rings, or cleaning the garden when rain suddenly starts.

The first clause sets the background. The second brings in the new event. It does not describe a separate action that the speaker deliberately decided to perform as the next step.

The activity need not cause the event. Talking about Maki does not make Maki enter the café: the coincidence is the point.

Think of it this wayPicture a background activity continuing across time, then place a new event inside that period: “I was in the middle of A when B happened.”

How to build the pattern

Vている + と
見ていると = while watching; 待っていると = while waiting. The first clause stays in this form even when the final verb reports a past event.
Vていた + ら
見ていたら = while I was watching; 掃除していたら = while I was cleaning. This is ていたら, not simply たら: the activity is already in progress.
Build the て-form first
歩く → 歩いていると／歩いていたら; 読む → 読んでいると／読んでいたら; 話す → 話していると／話していたら.
Event endings
電話が鳴った = the phone rang; 雨が降り出した = rain began to fall; 人が入ってきた = someone came in. These bring a new event into the scene.
What “unexpected” means here
The speaker reports what happened during the activity. It can be an ordinary phone call; you do not need 突然 or 偶然 to make the pattern work.

Read the Japanese and translation, then identify what is happening before and after the connector.

Book wording and English gloss
Book formation

　ている ＋と
　ていたら

Chance event: Vている + と, or Vていた + ら.

Book explanation

「～のをしているときに、…が。」～は「～ていると・～ていたら」のが。…はので、のを、がある。

While A is in progress, B happens by chance. A often uses ていると or ていたら. B reports a new, somewhat unexpected event rather than the speaker’s deliberate next step.

Book example

B①12テレビをいると、アメリカのからがかかってきた。

While I was watching television around midnight, a friend in America called me.

Clue Television watching is the background; the incoming call is the new event.

How to read this example

見ていると keeps the activity in progress, and かかってきた places the call in the past.

Book example

②コーヒーショップでマキさんのうわさをしていると、マキさんがきた。

While we were talking about Maki at a coffee shop, Maki happened to walk in.

Clue The coincidence is that the person being discussed walks in.

How to read this example

うわさをしていると supplies the ongoing conversation; 偶然 explicitly flags chance.

Book example

③のをしていたら、が。

While I was cleaning the garden, heavy rain suddenly began to fall.

Clue Rain starts during the garden cleaning.

How to read this example

掃除していたら sets the background, while 突然 and 降り出した mark the sudden onset.

Added examples

Apply the same distinction in these additional situations.

Added example

いると、のに。

While I was walking, I ran into an old friend.

Clue The friend is encountered during the walk.

How to read this example

歩いていると presents walking in progress; 会った reports the meeting, not an appointment arranged by the connector.

Added example

をしていたら、が。

While I was cooking, the phone rang.

Clue The phone interrupts the cooking scene.

How to read this example

料理をしていたら describes what was already underway; 鳴った introduces the ringing.

Added example

でをいると、がきた。

While I was reading a book in the park, it started to rain.

Clue The rain begins while the person is reading.

How to read this example

読んでいると supplies the ongoing action, and 降ってきた brings the developing weather into the scene.

Added example

をいたら、が。

While I was waiting for the train, my teacher arrived.

Clue Waiting is in progress when the teacher arrives.

How to read this example

待っていたら does not mean the speaker intentionally summoned the teacher.

Do not confuse it with…

ていると ↔ dictionary form + と
待っていると focuses on the waiting already in progress. 開けると can focus on the opening that reveals or triggers something. Check aspect—the stage of the action—not just the shared と.
Chance ↔ cause
Cleaning when it rains is a coincidence. Pressing a button and starting music is a trigger and response. Compare caused results.
ていると／ていたら ↔ 間に
Both can locate an event inside a period. 間に mainly gives the time window; this Group H pattern presents an event encountered during the activity. Review 間 and 間に.
Chance ↔ ついでに
ついでに adds another action taken as an opportunity while doing the main task. It often involves a deliberate extra errand. Review ついでに.

JLPT approach

  1. Find the background activity: waiting, walking, watching, or working. The progressive form often supplies the strongest clue.
  2. Then find the event that enters the scene. Separate へびが出てきた, “a snake appeared,” from へびを捕まえた, “I caught a snake.”
  3. Read the whole pair of clauses. ていたら can have other meanings elsewhere; it is not a universal signal that every following action is accidental.

Use clues to interpret the whole sentence. A single word is not a guaranteed answer shortcut.

Useful expression

帰っていると、友だちに会いました。

かえっていると、ともだちにあいました。

While I was on my way home, I ran into a friend.

Here 帰っている describes the journey in progress, and meeting the friend is the event encountered along the way.

Book grammar · action as trigger

～と…た・～たら…た　C

Triggered result: “I did A, and that brought about B.”

MeaningFormsExamplesComparisonsJLPT tips

Meaning in plain English

The first action is the trigger for a new result. A letter brings a reply, opening a box makes a toy spring out, or adding a little alcohol changes a dish’s flavor.

The second clause reports the response or change that actually occurred. It does not express a fresh instruction, invitation, or plan from the speaker.

This use can include an unplanned physical or emotional response. 踊りたくなった reports becoming inclined to dance; it differs from directly stating a present wish, 踊りたい.

Think of it this wayAsk whether A helped bring B about. If B began or changed because of A, this is a triggered result rather than an already-existing discovery.

How to build the pattern

Dictionary form + と
押すと、音楽が流れた = I pressed it and music started. The past ending reports this particular occasion.
た-form + ら
開けたら、風が入ってきた = when I opened it, wind came in. 開ける → 開けた → 開けたら.
Trying an action: Vてみる
振ってみると／入れてみたら includes “try doing.” Attach と to みる or ら to みた; do not treat てみる as a separate result.
A resulting change: ～く／に なった
いい味になった = it developed a good flavor; 踊りたくなった = I came to feel like dancing. The change is what followed the trigger.
Typical response verbs
返事が来た, 音がした, 風が入ってきた, 熱が下がった. Follow the grammatical subject: the reply comes, the sound occurs, the wind enters, the fever drops.

Book examples, with clues

Read the Japanese and translation, then identify what is happening before and after the connector.

Book wording and English gloss
Book formation

　 ＋と
　たら

Triggered result: verb dictionary form + と, or verb た-form + ら.

Book explanation

「～のがきっかけになって、…が。」…はので、のを。

Doing A triggers B. The second clause reports the event or result that occurred, rather than expressing the speaker’s intention.

Book example

C①にのにをと、すぐにが。

I wrote to my high school teacher for the first time in a long while, and a reply came right away.

Clue Sending the letter prompts a reply.

How to read this example

出すと connects the initiating action to 返事が来た; すぐに emphasizes the quick response.

Book example

②をと、おもちゃが。

When I opened the box, a toy sprang out.

Clue Opening the box triggers the toy’s movement.

How to read this example

飛び出した is a new event; compare 人形が入っていた, where the contents were already there.

Book example

③にちょっとおをみたら、いいになった。

I tried adding a little alcohol to the dish, and it developed a nice flavor.

Clue Adding alcohol changes the flavor.

How to read this example

入れてみたら includes trying an action; いい味になった reports the resulting taste.

Added examples

Apply the same distinction in these additional situations.

Added example

ボタンをと、が。

When I pressed the button, music started playing.

Clue The button press starts the music.

How to read this example

流れた reports one past response; 流れる would instead suit a general explanation of how the device works.

Added example

を、がきた。

When I opened the window, wind came in.

Clue Opening the window allows wind to enter.

How to read this example

入ってきた describes a new movement toward the inside, rather than wind already present there.

Added example

をと、が。

When I took the medicine, my fever went down.

Clue Taking the medicine is followed by a drop in fever.

How to read this example

下がった is the observed result on this occasion; this grammar sentence is not a claim that every dose always has the same effect.

Added example

を、がきた。

When I called its name, the dog came running.

Clue The dog responds to hearing its name.

How to read this example

呼んだら gives the trigger, while 走ってきた says the dog came running toward the caller.

Do not confuse it with…

A trigger ↔ a discovery
A sound that starts when you shake a toy is a new effect. A letter already in a drawer is a discovered fact. Compare discovery states.
A past result ↔ a general rule
ボタンを押すと、音楽が流れた reports one result. ボタンを押すと、音楽が流れる explains what the device does. The final tense and context distinguish the reading.
A result ↔ the same person’s next action
A toy springs out in response to opening; a teacher enters and then hands out papers. The latter follows one actor through a sequence. Compare immediate sequences.
なる ↔ する
熱が下がった and いい味になった describe outcomes. A person can intentionally cause a change even when the result uses なる. Review Group G: changes and deliberate adjustments.

JLPT approach

  1. Classify the second clause as a response or change. You should be able to explain the link with the first action.
  2. Compare した and していた carefully: a sound produced by shaking fits した; していた would describe a sound already continuing.
  3. Do not reject a result merely because it concerns a feeling. “Became wanting to…” reports a change; “I want to…” directly expresses a wish.

Use clues to interpret the whole sentence. A single word is not a guaranteed answer shortcut.

Useful expression

再起動してみたら、直りました。

さいきどうしてみたら、なおりました。

I tried restarting it, and it started working properly again.

A useful way to report a troubleshooting result. 直りました names the observed recovery; it does not claim that restarting always solves the problem.

Book grammar · immediate same-subject sequence

～と…た

Immediate sequence: “As soon as the person did A, they did B.”

MeaningFormsExamplesComparisonsJLPT tips

Meaning in plain English

The same person performs two actions in quick succession. The teacher enters the classroom and immediately starts handing out the test. The narration follows that person from one action to the next.

The second action can be deliberate. What matters is that the sentence reports a completed sequence; it is not a new instruction or a statement of what the speaker intends to do in a future hypothetical situation.

This is why “と cannot be followed by a deliberate verb” is too broad. Compare a past report, 配り始めた, with an invitation or intention such as 配りましょう.

Think of it this wayTrack one actor through both clauses. If A is immediately followed by that person’s B, read it as a sequence in the story.

How to build the pattern

V dictionary form + と + past action
入ると、座った; 読むと、部屋を出た. The first verb remains nonpast in this narrative pattern.
Keep the same actor
先生は入ってくる → 先生は配り始めた. The second subject is commonly omitted because the person has not changed.
Timing words help
すぐ = immediately. The pattern can still imply a quick next step without すぐ; do not require that exact word in every question.
てしまった adds a viewpoint
逃げていってしまった adds the sense that the person ended up fleeing or went off completely. It does not create the と sequence by itself.
Simple action chaining: Vて
窓を開けて外を見た neutrally links opening the window and looking outside as the speaker’s actions. The book contrasts this with its discovery and immediate narrative patterns.

Book examples, with clues

Read the Japanese and translation, then identify what is happening before and after the connector.

Book wording and English gloss
Book formation

　 ＋と

Immediate narrative sequence: verb dictionary form + と.

Book explanation

「～のの、すぐ…した。」～と…のは。

The same person does A and then immediately does B. Both actions are narrated as events that happened.

Book example

①そのはわたしのをと、すぐにいってしまった。

As soon as the man saw my face, he ran off.

Clue The same man sees the speaker and runs away.

How to read this example

と carries the narration directly to the next action; てしまった adds a sense of the completed departure.

Book example

②はにくると、すぐを。

As soon as the teacher entered the classroom, they started handing out the test papers.

Clue The teacher enters and immediately starts distributing the papers.

How to read this example

配り始めた is a past action by the same actor, not an instruction to the class.

Book example

③はからと、どこかにをかけた。

As soon as Yukiko got off the plane, she made a phone call somewhere.

Clue Yukiko gets off the plane and then makes a call.

How to read this example

どこかに means to somewhere; the destination of the call is left unspecified.

Expanded explanation

Unlike the discovery use, the same person performs both actions. The second action follows immediately and is narrated as a completed event.

Added examples

Apply the same distinction in these additional situations.

Added example

はにと、すぐを。

As soon as Tanaka sat down, they started working.

Clue Tanaka takes a seat and starts work straight away.

How to read this example

席に着く is “take one’s seat”; すぐ makes the quick sequence explicit.

Added example

はをと、を。

After reading the letter, he left the room.

Clue He reads the letter and then leaves the room.

How to read this example

The same subject continues through both verbs; this is not a discovery of another person already outside.

Added example

はにと、かばんを。

As soon as the child got home, they put down their bag.

Clue The child gets home and puts down the bag.

How to read this example

The sentence follows two actions by the child in quick succession.

Added example

はをと、すぐした。

As soon as the company president heard the explanation, they asked a question.

Clue The president hears the explanation and immediately asks a question.

How to read this example

Asking is deliberate but reported as an actual past event; it is not a future request or intention after conditional と.

Do not confuse it with…

Same actor ↔ changed scene
先生は入ると配り始めた follows the teacher’s two actions. 教室に入ると先生がいた reveals a different person already there. Review discovery.
Past narrative ↔ hypothetical intention
A report such as 彼は読むと出ていった differs from a future plan ending 出ていこうと思う. Apply the conditional restrictions to the appropriate reading. Practice sentence endings.
Immediate と ↔ てから
てから makes “after finishing A” explicit but does not itself require B to happen immediately. Compare Lesson 1’s てから patterns.
と ↔ たら in these questions
たら has broad uses, including past experiences. In the book’s sequence questions, choose と for the intended immediate third-person narration. Do not turn that preference into a ban on all past sentences with たら.

JLPT approach

  1. Identify the actor before and after the connector. An omitted subject can still be the same person.
  2. Check whether B is an observed past action or a wish, offer, request, or intention. A polite verb can be either a factual report or an offer depending on context.
  3. Translate only after identifying the relationship. English “when” can hide the differences among all four patterns.

Use clues to interpret the whole sentence. A single word is not a guaranteed answer shortcut.

Useful expression

彼女はメッセージを読むと、すぐ返事を書いた。

かのじょはメッセージをよむと、すぐへんじをかいた。

As soon as she read the message, she wrote a reply.

The same woman reads and writes. This narrates what she did, rather than asking what she will do if she receives a message.

Book grammar · paired qualities and facts

～も…ば～も…・～も…なら～も…

Adding two facts: “both A and B” or “neither A nor B.”

MeaningFormsExamplesComparisonsJLPT tips

Meaning in plain English

Two occurrences of も pair facts or qualities. This town has both sea and mountains; someone is good at both cooking and cleaning. In this use, ば or なら connects the two descriptions rather than making one depend on the other.

The facts can be similar, contrasting, positive, or negative. Life has enjoyable times and difficult times. With two negatives, the meaning is “neither…nor…” or “not…either.”

Read both clauses before deciding that ば means “if.” The second も and the sense of listing are the main clues.

Think of it this wayReplace the middle connection with “and also.” If the two statements are being added together, you have the paired-facts use.

How to build the pattern

Nも + verb ば-form + Nも…
海もあれば山もある. For a 五段 verb, change the final u-sound to the e-row and add ば: 飲む → 飲めば, 話す → 話せば. 一段: 食べる → 食べれば. Irregular: する → すれば; 来る → 来れば（くれば）.
Nも + い-adjective ～ければ + Nも…
安い → 安ければ; 楽しい → 楽しければ. いい uses よければ. Do not attach なら merely because the English describes a quality.
Nも + な-adjective／noun + なら + Nも…
料理も上手なら掃除も得意だ; 前回も雨なら今回も雨だ. Use 上手なら／雨なら, without な or だ before なら.
Pairing negative facts
会ったこともなければ、名前を聞いたこともない. ない → なければ. Keep the second negative: “I have neither met the person nor heard their name.”
Potential before ば
話せる → 話せれば = can speak; 話す → 話せば = speak. The extra れ distinguishes the potential form. Both can be conjugated with ば, but the meanings differ.
The two facts need not use identical predicates
スポーツも好きならピアノも弾く pairs liking sports and playing piano. Do not force the second half to copy the first verb or adjective.

Book examples, with clues

Read the Japanese and translation, then identify what is happening before and after the connector.

Book wording and English gloss
Book formation

＋も ＋［　ば／イ　～ければ／ナ　なら／　なら］＋＋も

Noun + も + [verb ば-form / い-adjective ～ければ / な-adjective or noun + なら] + noun + も + a second predicate.

Book explanation

「～も…し、～も…・～も～も…。」「も」を２。

Use も twice to add two facts: “both…and….” Two negatives give “neither…nor….” This use of ば or なら does not express an ordinary hypothetical condition.

Book example

①にはもあればつらいもある。

Life has enjoyable times as well as difficult times.

Clue Enjoyable times and difficult times are both part of life.

How to read this example

時もあれば…時もある pairs contrasting facts; one kind of time is not a condition for the other.

Book example

②はおもよくばもたくさん。

My wife drinks plenty of alcohol and also eats lots of sweets.

Clue The sentence adds two habits of the wife.

How to read this example

飲めば here is the ば-form of 飲む, “drink”; potential “can drink” would be 飲めれば.

Book example

③そんな、こともなければをこともありません。

I have never met that person, and I have never even heard their name.

Clue Both clauses are negative.

How to read this example

会ったこともなければ…聞いたこともない means neither experience has happened; なければ does not mean “unless” in this pairing.

Book example

④はが。スポーツもならピアノも。

Matsumoto has many hobbies. They like sports, and apparently they play the piano too.

Clue Two interests are added, with らしい marking reported information about piano playing.

How to read this example

好き is a な-adjective, so the first link is 好きなら.

Book example

⑤もならもか……。ぼくたちのはいつもがね。

It rained last time, and it is raining this time too… Our trips always seem to be unlucky.

Clue The complaint pairs rain on the previous trip and this trip.

How to read this example

雨 is a noun, so 雨なら connects the facts; か…… conveys the speaker’s disappointed reaction.

Added examples

Apply the same distinction in these additional situations.

Added example

このはもあればもある。

This town has both the sea and mountains.

Clue The town has two geographic features.

How to read this example

海もあれば山もある lists their presence rather than suggesting mountains depend on the sea.

Added example

はもばも。

He can speak both English and Chinese.

Clue The sentence lists two language abilities.

How to read this example

話せれば is potential 話せる + ば; keep the extra れ when you mean “can speak.”

Added example

このはもばもいい。

This restaurant has low prices and good food.

Clue Price and taste are both favorable.

How to read this example

安い becomes 安ければ, while the second description 味もいい adds another advantage.

Added example

はもならもだ。

My older brother is good at both cooking and cleaning.

Clue The brother has two skills.

How to read this example

上手 is a な-adjective, so use 上手なら; the second も pairs cleaning with cooking.

Do not confuse it with…

Paired facts ↔ an ordinary condition
海もあれば山もある lists two things the town has. 時間があれば行く makes having time a condition for going. The presence of ば alone does not settle the meaning.
Paired なら ↔ responding to a premise
料理も上手なら掃除も得意だ adds two skills. 暇なら手伝って responds to “if you are free.” Review conditional なら.
も…ば…も ↔ し…し
Both can list qualities or facts. し often gives reasons for a conclusion; the paired も construction draws attention to the two included facts. Read the surrounding sentence to see whether a conclusion follows.
Negative pairing ↔ ば…ほど
も…なければ…もない lists two absences. ば…ほど describes a linked increase or change: “the more…, the more….” Review proportional change.

JLPT approach

  1. Find both も markers. Then decide whether the sentence is adding facts or actually setting a condition.
  2. Check the predicate just before the blank: verb, い-adjective, な-adjective, or noun. That controls ば／ければ／なら.
  3. Keep the polarity of the whole message. If the conclusion says a trip is impossible, two shortages may be intended rather than an available resource.

Use clues to interpret the whole sentence. A single word is not a guaranteed answer shortcut.

Useful expression

この部屋は日当たりもよければ、交通の便もいい。

このへやはひあたりもよければ、こうつうのべんもいい。

This room gets good sunlight and also has convenient transport access.

よければ comes from いい. The sentence adds two advantages; good sunlight is not a condition that causes good transport access.

Shin Kanzen Master N3 Grammar, Group H, printed pages 88–89. The English notes explain these patterns and add comparisons; the Japanese examples keep their wording and order.

Book one-point lesson · page 91

仮定を表す「～たら…・～ば…・～と…」の注意

7 questions · which endings fit the condition? Read both halves: first identify an action, state, or possibility; then identify a result, wish, request, offer, invitation, or intention.

The book allows both answers where both are appropriate. Checkboxes let you select more than one; choose all valid options. The review explains each valid sentence separately. Submit all seven questions, or use the two optional hints if you need a clue.

◎どちらか適当な方を選びなさい。（両方いい場合もあります。）

1　車を（a 貸してもらえると　b 貸してもらえれば）、ドライブに行きたい。

2　早く仕事が終わったら、（a 飲みに行けるね　b 飲みに行きませんか）。

3　早く予約すれば、（a いい席を取る　b いい席が取れる）。

4　部屋が暑ければ、（a 窓を開けてください　b 窓を開けますよ）。

5　時間が（a なければ　b なかったら）、買い物はあきらめるつもりだ。

6　マフラーを（a 作れば　b 作ったら）、彼にあげようと思う。

7　店の（a 電話番号を調べれば　b 電話番号がわかれば）、電話してみます。

A decision guide for hypothetical conditions

Read the ending before choosing the connector. A past report about what someone did is different from an intention about what someone will do if a condition is met.

たら: broad choice of endings
Results, wishes, invitations, requests, and plans can follow. 作ったら gives “when / after I have made it.” The た in this conditional does not by itself mean that the whole sentence happened in the past.
と: a stated result
In these hypothetical comparisons, と does not introduce the speaker’s wish, request, invitation, or plan. Compare 買える, “can buy,” with 買いたい, “want to buy.” Past narrative と is a separate use.
ば after an action: check the ending
In the book’s action-condition examples, use a result or possibility after ば. A planned next action by the same person is better introduced with たら: 作ったら…あげようと思う.
ば after a state: wishes and requests can fit
Adjectives and state expressions such as 暑い, 時間がない, わかる, and potential verbs can introduce these endings with ば. Check what the predicate means; not every verb describes a deliberate action.

Conjugation clues

暑い → 暑ければ; ない → なければ／なかったら; わかる → わかれば; もらえる → もらえれば; 作る → 作れば／作ったら. Potential 取れる means “can get”; ordinary 取る means “get / take.”

Keep the rule within its context: this is the book’s guided contrast, not a complete ban covering every use of ば. Meaning, context, and usage variation affect acceptability. Choose the form that matches the specific relationship and ending being tested.

Compare past narrative と, review Lesson 6’s conditionals, or review potential and resulting states in Group G.

Book explanation · movement verbs

※～が動きを表す動詞の場合

When the condition describes an action or event. Here 動き includes actions and happenings, not only physical movement.

「～たら…」の…はどんなでもいいが、「～ば…・～と…」の…にはのをやのは。

For the action/event conditions illustrated here, たら can be followed by a wish, intention, invitation, or request. The book contrasts this with と and action-condition ば, which take a stated result rather than those endings in these examples. Read this together with the state-condition rule below.

Book example · ×

×　大雪が降ると家にいよう。

Unsuitable here: “If it snows heavily, let’s stay home.” Use 降ったら before this proposal.

Clue The × marks an unsuitable conditional sentence in this comparison.

How to read this example

家にいよう is a volitional “let’s stay home”; use 大雪が降ったら to introduce that proposal.

Book example · ×

×　大雪が降れば家にいなさい。

Unsuitable in the book’s comparison: “If it snows heavily, stay home.” Use 降ったら before this instruction.

Clue The × marks the book’s action-condition restriction on ば.

How to read this example

家にいなさい is an instruction; 大雪が降ったら is the suitable connector for this example. Do not apply this restriction to the state-condition examples below.

Book example · ○

○　大雪が降ると／降れば出かけられない。

Acceptable: “If it snows heavily, we cannot go out.” Both と and ば fit this result.

Clue The ○ marks a stated inability as the result.

How to read this example

出かけられない means “cannot go out,” not “let’s not go out,” so both 降ると and 降れば fit.

Book explanation · adjectives and state verbs

※～が形容詞や状態を表す動詞（ある・いる・できるなど）の場合

When the condition is an adjective or a state expression, such as ある, いる, or できる.

「～たら…・～ば…」の…はどんなでもいいが、「～と…」の…にはのをやのは。

With an adjective or a state expression such as ある, いる, or a potential verb in the condition, ば as well as たら can precede wishes, intentions, requests, and invitations. Conditional と still does not take those endings in this comparison.

Book example · ×

×　お金があると車を買うつもりだ。

Unsuitable here: “If I have money, I intend to buy a car.” Use あれば or あったら before this intention.

Clue The × marks a future intention following conditional と.

How to read this example

買うつもりだ states the speaker’s plan; replace あると with あれば or あったら for this meaning.

Book example · ○

○　お金があれば車を買いたい。

Acceptable: “If I have money, I want to buy a car.”

Clue The ○ shows that state-condition ば can precede a wish.

How to read this example

お金がある describes available resources; あれば can therefore lead to 買いたい in this comparison.

Book example · ○

○　お金があると／あれば車が買える。

Acceptable: “If I have money, I can buy a car.” Both と and ば fit this result.

Clue The ○ marks a potential result rather than a wish.

How to read this example

買える means “can buy,” whereas 買いたい means “want to buy”; this difference allows both あると and あれば here.
